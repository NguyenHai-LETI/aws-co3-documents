### 4. `ai-20261017-0823-04` · networking · PrivateLink, NLB, VPC Endpoint

> A SaaS company hosts a payment-validation API on EC2 instances in its own VPC. More than 2,000 customers, each with their own AWS accounts and VPCs, must call the API. Many customer VPCs use CIDR ranges that overlap with the provider VPC and with each other. Customers must reach only this API, not the rest of the provider network, and the traffic must not traverse the internet. Which solution sho…

- Bạn chọn: **A.** Attach every customer VPC to a shared Transit Gateway and restrict access with route table segmentation
- Đáp án đúng: **B.** Publish the API as a VPC endpoint service behind an NLB and have customers create interface endpoints
- Giải thích: AWS PrivateLink exposes a single service behind a Network Load Balancer as an endpoint service; consumers create interface endpoints in their own VPCs, so overlapping CIDRs do not matter and only the API is reachable. - Shared Transit Gateway: routes whole networks and cannot route between overlapping CIDRs. - VPC peering per customer: fails with overlapping CIDRs and does not scale to thousands of peers. - Internet-facing ALB with WAF: the traffic crosses the internet. > 🇻🇳 Cung cấp 1 dịch vụ riêng tư cho rất nhiều VPC khách (CIDR trùng) → PrivateLink (NLB + endpoint service).
