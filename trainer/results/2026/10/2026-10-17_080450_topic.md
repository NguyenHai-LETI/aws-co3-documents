### 1. `17-v1-04` · networking · Route 53 Resolver, VPC

> On-premises servers must resolve DNS names of resources in a VPC (and vice versa) for hybrid DNS. Which feature?

- Bạn chọn: **B.** Route 53 public hosted zone
- Đáp án đúng: **D.** Route 53 Resolver inbound/outbound endpoints
- Giải thích: Hybrid DNS on-prem <-> VPC = Route 53 Resolver endpoints.

### 2. `04-v2-25` · networking · PrivateLink, VPC Peering

> Two VPCs with OVERLAPPING CIDR blocks must share access to specific services. VPC peering is not possible. Which approach works?

- Bạn chọn: **B.** VPC peering with route tables
- Đáp án đúng: **C.** AWS PrivateLink to expose specific endpoints (no full network merge)
- Giải thích: Overlapping CIDRs, expose specific services = AWS PrivateLink.

### 5. `17-v1-03` · networking · VPC, VPC Flow Logs

> A security team must investigate which source/destination IPs were ACCEPTED or REJECTED for traffic in a VPC subnet. Which feature provides this data?

- Đáp án đúng: **D.** VPC Flow Logs
- Giải thích: Accepted/Rejected IP traffic detail = VPC Flow Logs.

### 6. `04-v2-19` · networking · Internet Gateway

> An IPv6-only workload in a private subnet needs outbound internet access but must not accept inbound connections. Which component?

- Bạn chọn: **A.** NAT Gateway
- Đáp án đúng: **C.** Egress-Only Internet Gateway
- Giải thích: IPv6 outbound-only, no inbound = Egress-Only Internet Gateway.

### 12. `04-v1-06` · networking · VPC Endpoint, VPC, S3

> A company wants private connectivity from a VPC to Amazon S3 and DynamoDB without using the internet, at no additional cost. Which is BEST?

- Đáp án đúng: **D.** Gateway VPC Endpoint
- Giải thích: Free private access to S3/DynamoDB = Gateway VPC Endpoint.

### 15. `04-v2-28` · networking · Transit Gateway, RAM

- Giải thích: 200 VPCs multi-account/Region = Transit Gateway inter-Region peering + share via AWS RAM.

### 16. `17-v1-19` · networking · Transit Gateway, VPC, RAM

### 17. `04-v1-08` · networking · CloudFront, S3

### 18. `04-v2-23` · networking · PrivateLink, VPC Endpoint, VPC Peering
